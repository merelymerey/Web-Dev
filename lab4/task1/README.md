# Task 1 – Official Angular Tutorial

Complete all steps of the official **Learn Angular** tutorial:

👉 https://angular.dev/tutorials/learn-angular

## Steps

1. Open the link above in your browser
2. Work through every lesson (there are 17 lessons covering components, templates, directives, services, routing, and HTTP)
3. After completing the tutorial, scaffold a local project if the tutorial provides a download link, or recreate the final project locally with `ng new`
4. Ensure `ng serve` starts without errors
5. Commit and push this folder to your GitHub repository

## What the tutorial covers

| Lesson | Topic |
|--------|-------|
| 1–4    | Components & templates |
| 5–7    | Data binding & events |
| 8–10   | Directives (*ngFor, *ngIf) |
| 11–13  | Services & dependency injection |
| 14–15  | Routing & navigation |
| 16–17  | HTTP & forms |
